# Ratshi's Eggs and Chicken

## Project Overview

Ratshi's Eggs and Chicken is a South African poultry business website developed as part of the WEDE5020 Web Development Introduction project. The website provides customers with information about the business, its poultry products, indicative prices, contact details and a product enquiry form.

The website aims to provide a simple and user-friendly online presence for the business.

## Project Goals

The main goals of the website are to:

- Provide information about Ratshi's Eggs and Chicken.
- Display the business's poultry products.
- Provide indicative product prices.
- Allow customers to make product enquiries.
- Provide business contact information.
- Provide clear and easy website navigation.

## Target Audience

The target audience includes:

- Individuals and households looking for eggs and chicken products.
- Customers interested in poultry products.
- Local customers who want information about products and prices.
- Customers who want to contact the business or make an enquiry.

## Website Pages

The website contains five main HTML pages:

### Home

Introduces Ratshi's Eggs and Chicken and provides an overview of the business.

### About Us

Provides information about the business, including its mission, vision and values.

### Products

Displays fresh eggs, chicken portions and whole chicken, including indicative project prices.

### Enquiry

Provides a form that allows customers to enquire about products, quantities, prices and availability.

### Contact

Provides business contact information, operating hours and planned business locations.

## File and Folder Structure

The project is organised as follows:

- `index.html` - Home page
- `about.html` - About Us page
- `products.html` - Products page
- `enquiry.html` - Enquiry page
- `contact.html` - Contact page
- `css/` - CSS files for the website
- `js/` - JavaScript files for later project development
- `images/` - Website images and logo

## Technologies

The project will use HTML5, CSS3 and JavaScript as the website develops through the three project parts.

Visual Studio Code is used as the development environment, while Git and GitHub are used for version control.

## Research and Content

Research was conducted to ensure that the website content is relevant to the South African poultry and agricultural environment.

The South African Poultry Association and Department of Agriculture were used as relevant sources for the project.

Images and other external assets will be properly acknowledged and referenced where applicable.

## Accessibility

Accessibility considerations included:

- Providing alternative text for images.
- Using clear headings.
- Providing labels for form fields.
- Using descriptive navigation links.
- Organising content logically.

## Testing

The HTML pages are tested by checking that:

- Each page opens correctly.
- Navigation links work.
- Images display correctly.
- Product information is displayed correctly.
- Forms are displayed correctly.
- There are no broken internal links.
